# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
If the plugin is hosted by the Jenkins project, the
[Jenkins Code of Conduct](https://www.jenkins.io/project/conduct/) applies instead.

Report unacceptable behaviour privately to the maintainers through the repository's
security reporting channel (see `SECURITY.md`), or by email to the address listed in the
repository profile.
